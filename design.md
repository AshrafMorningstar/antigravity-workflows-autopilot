# 04 Frontend & UI Specification Document — Antigravity Workflows Autopilot

## 1. Design Philosophy
Minimalist, high-performance dark mode studio aesthetic with glassmorphism overlays, subtle indigo glow effects, clean typography, and zero layout shift. Accessible for beginners while offering advanced power features for experienced developers.

## 2. Color Palette (HSL Tailored Dark Theme)
- **Background Main**: `#0a0b0f`
- **Card Background**: `#111218`
- **Panel Background**: `#14151d`
- **Border Default**: `rgba(255, 255, 255, 0.07)`
- **Accent Primary**: `#6366f1` (Indigo)
- **Accent Secondary**: `#8b5cf6` (Purple)
- **Status Green**: `#10b981` (Emerald)
- **Status Yellow**: `#f59e0b` (Amber)
- **Status Red**: `#f43f5e` (Rose)
- **Text Primary**: `#f8fafc`
- **Text Muted**: `#94a3b8`

## 3. Typography & Micro-Interactions
- **Body & UI**: `Inter`, system-ui, sans-serif.
- **Monospace Code**: `JetBrains Mono`, monospace.
- Smooth scale transformations (`transform: translateY(-2px)`), card hover glows (`rgba(99, 102, 241, 0.25)`), and animated real-time terminal streaming logs.

## 4. Child-Friendly Terminal Interface Design
- Clear 1-digit numerical choice menu (1 to 6).
- Emoji indicators (🚀, 🤖, 📁, 🔍, 🛠️, ❌).
- Instant status indicators and friendly zero-jargon instructions.
